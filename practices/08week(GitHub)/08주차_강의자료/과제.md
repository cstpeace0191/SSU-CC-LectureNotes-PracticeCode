# 8주차 과제 (강의노트 40쪽)

## 과제 1. 기능 PR

`GET /api/items?q=검색어` (이름 부분 일치) 기능을 Issue 로 등록하고 PR 로 구현합니다.

- [ ] Issue Form(`feature_request.yml`)으로 등록하고 수용 기준을 적는다
- [ ] 브랜치 이름: `feat/<이슈번호>-search`
- [ ] 테스트 3개 이상: 일치 · 불일치 · 대소문자 등 경계값 (`backend/spec/routes/test_filterItems.py` 참고)
- [ ] PR 템플릿을 채우고 제목은 Conventional Commits 형식 (`feat(api): ...`). `pr-title.yml` 이 검사함
- [ ] PR 본문에 `Closes #<이슈번호>`

**제출:** 저장소 URL, PR 링크

## 과제 2. 코드 리뷰

- [ ] 동료 PR 하나에 인라인 코멘트 3개 이상 (Suggested change 1개 포함)
- [ ] Start a review 로 모아서 Request changes 로 제출
- [ ] 반영 커밋 확인 후 Approve
- [ ] 리뷰 관점은 강의노트 25쪽 체크리스트 (정확성 · 호환성 · 테스트 · 데이터 · 보안 · 성능 · 운영 · CI)

**제출:** Request changes → 반영 → Approve 기록이 보이는 PR 링크

## 과제 3. CI 확장

- [ ] `ci.yml` 에 `services: mysql:9.3` 을 쓰는 job 추가
- [ ] `backend/pyproject.toml` 의 `omit` 에서 `src/persistence/mysql.py` 를 빼서 커버리지에 다시 포함
- [ ] 새 job 이름을 필수 검사에 등록 (`03_PullRequests_CodeReview/브랜치보호_적용방법.md`)

**제출:** 통과한 Actions 실행 링크
